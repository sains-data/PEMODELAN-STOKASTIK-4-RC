# PEMODELAN-STOKASTIK-4-RC
Analisis pemodelan stokastik dalam sistem antrian M/M/1 PADA LAYANAN PENGISIAN PERTALITE UNTUK PENGENDARA MOTOR DI SPBU ITERA 

# 🚀 Analisis Sistem Antrian M/M/1 pada Layanan Pengisian Pertalite Motor – SPBU ITERA

Penelitian ini bertujuan menganalisis efisiensi sistem antrian pada layanan pengisian Pertalite untuk kendaraan roda dua di SPBU ITERA menggunakan pendekatan **Pemodelan Stokastik M/M/1**.  
Data diperoleh melalui observasi langsung, kemudian diolah menggunakan **R** untuk menghitung parameter antrian serta mengevaluasi stabilitas sistem.



## 📌 Ringkasan Penelitian

- **Lokasi:** SPBU ITERA – Jalur Motor  
- **Model yang digunakan:** Antrian **M/M/1**  
- **Data diperoleh dari:** Observasi lapangan (Interarrival Time & Service Time)  
- **Bahasa Pemrograman:** R  
- **Tujuan utama:**  
  - Mengukur laju kedatangan (**λ**)  
  - Mengukur laju pelayanan (**μ**)  
  - Menilai tingkat utilisasi (**ρ**) & stabilitas sistem  
  - Menghitung ukuran kinerja: Lq, Wq, L, W
